\## Fonts — mandatory, no exceptions

\- Display font: Fraunces (weights 700, 900) — headings, titles, large numerals

\- Body font: DM Sans (weights 400, 500, 700) — instructions, buttons, labels

\- Japanese font: Noto Sans JP (weights 400, 700) — all hiragana, katakana, kanji

\- Never substitute these fonts for any reason

\- Always import from Google Fonts using exactly this string:

&#x20; @import url('https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,700;9..144,900\&family=DM+Sans:wght@400;500;700\&family=Noto+Sans+JP:wght@400;700\&display=swap');
